# Brand assets

`taste-wordmark.svg` is the TASTE wordmark, a trademark of Taste Labs. taste-cli is unofficial, not affiliated with Taste Labs, built on the Taste Engine API. The wordmark is used only to style the page shown after signing in, so it reads as the service the sign in is for. It is not covered by the [MIT licence](../../LICENSE) and will be removed if Taste Labs asks.

The file is Taste Labs' wordmark with its fill set to `currentColor`. `src/auth/wordmark.ts` inlines it, and a test keeps the two identical.
