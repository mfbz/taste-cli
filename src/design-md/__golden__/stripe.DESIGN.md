# Stripe

## Overview

Clean, light-mode interface dominated by white backgrounds with subtle gradient accents in purple and warm tones. Premium typography using the proprietary Söhne font creates a sophisticated, modern aesthetic. Interactive product visualizations and animated UI mockups demonstrate technical sophistication while maintaining visual clarity.

- **Style:** Flat Design, Corporate
- **Industry:** FinTech / Payments Infrastructure
- **Tone:** Confident, Technical, Precise
- **Keywords:** sophisticated, technical, modular, premium, precise, gradient-rich
- **Accents:** Purple primary accent (#533afd) used for CTAs and interactive elements, with warm gradient transitions (orange, magenta) appearing in product illustrations and animated graphics to add visual warmth and distinguish feature categories
- **Highlights:** Animated wave graphics, interactive bento card layouts with hover states, globe visualization for global stats, and subtle glow effects on product mockups to draw attention to key functionality

## Colors

The palette is highly restrained, relying on a stark high-contrast duo of deep navy text on white surfaces, which makes the signature 'Blurple' pop as an interactive accent.

Depth is achieved not through heavy shadows, but through a wide array of extremely subtle off-white and cool gray-blue tints used for card backgrounds and borders.

Information density in product illustrations is managed gracefully using a monochromatic scale of slate grays, ensuring complex data tables remain legible without feeling cluttered.

- **Black (#000000):** Used for base document text, drop shadows, and external brand logos.
- **Blurple (#533AFD):** The brand's signature accent color, used exclusively for primary actions, links, and vibrant graphical highlights.
- **Deep Navy (#061B31):** The primary high-contrast text color for headings, navigation, and critical data points.
- **Slate Gray (#50617A):** A secondary text color for supporting copy, metadata, and subtle UI elements.
- **White / Off-White (#FFFFFF):** The foundational surface color providing clean contrast for text, cards, and section layouts.

## Typography

Strong emphasis on light typography: Almost all headings and large text variants use a light font-weight (300), creating a very sleek, confident, and modern aesthetic.

Fluid modular scale: The typography system uses a robust set of CSS custom properties and viewport-based media queries to perfectly scale headings and text for desktop, tablet, and mobile.

Negative letter spacing on large type: Heading XL and XXL use tighter negative letter spacing (-0.02em, -0.025em), ensuring large headings remain optically balanced.

## Layout

Uses a responsive 4/8/12-column grid system with consistent 16px gutters and a 1264px max content width, allowing flexible card-based layouts that adapt seamlessly across breakpoints.

Visual rhythm is established through generous vertical spacing (increasing from 56px mobile → 96px desktop between sections) and alternating light/dark sections—white content areas contrast with deep blue-to-purple gradient hero moments for emphasis.

Compositional strategy favors centered, symmetric layouts for hero/titles, then breaks into card grids (4-column, 3-column, 2-column) that dynamically reflow; prominent use of gradient overlays (orange/pink/purple) on imagery and UI elements reinforces brand identity and adds energy.

Alternating white backgrounds with gradient overlays; dark sections (stats) use deep blue-to-purple gradients for contrast; subtle dashed borders between major content blocks; generous whitespace (56px mobile, 64px tablet, 96px desktop) creates clear visual breathing room between sections; promotional banners use full-bleed imagery with overlay content.

- **Mobile:** 0px - 639px (4 Columns, 16px gutter)
- **Tablet:** 640px - 939px (8 Columns, 16px gutter)
- **Desktop:** 940px - 1297px (12 Columns, 16px gutter)
- **Large:** 1298px+ (12 Columns, 16px gutter, 1264px max content width)

- Subtle dot pattern and wave graphics as background decorations
- Animated gradient borders on modular solutions bento cards

## Components

- **Get started (Primary):** Main call-to-action for user registration and onboarding flows. Appears in hero sections and key conversion points.
- **Contact sales (Secondary on Quiet):** Secondary action buttons used alongside primary CTAs. Appears in navigation and hero sections for sales inquiries.
- **Read the story (Secondary):** Secondary action for customer story cards and case study links. Used in accordion-style customer story sections.
- **Sign up with Google (Secondary with Icon):** OAuth authentication button for Google sign-up flow in hero section.
- **Products/Solutions/Developers (Navigation Trigger - Transparent):** Navigation menu triggers that expand dropdown menus. Used in the main header navigation.
- **Watch now (Primary on Dark):** Primary CTA button on dark backgrounds, such as the Sessions on-demand banner section.
- **Chat now with sales (Dark Mode):** Chat initiation button on dark backgrounds, appears in dark themed sections for sales contact.
- **Query Submit (Icon Button - Disabled State):** Icon-only submit button for the query input form. Circular design with arrow icon.

Horizontal button groups with primary and secondary actions side by side. Primary button appears first, followed by secondary outline button.

The design system uses a consistent cubic-bezier(0.25, 1, 0.5, 1) easing curve across all micro-interactions, creating a unified feel of swift entry with soft deceleration.

Button radius is kept minimal at 4px (rounded) maintaining a professional, fintech-appropriate aesthetic while still feeling modern and approachable.

Heavy use of CSS custom properties (--hds-*) enables theming between light/dark modes and accent color variations without component duplication, seen in the stats section time-of-day gradients.

Interactive elements follow a consistent disabled state pattern: 0.5 opacity background tint, muted gray text (#95A4BA), and cursor: default/not-allowed.
